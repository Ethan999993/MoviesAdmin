This is the app for administrators to use for a movie review website  being created for Web application  programming at NSCC. 
The will allow administrators to create remove update and delete data for movies. 
At a later date the public side of the website along with a api app and a database  will also be created and used along side this admin program


This is being created in visual studios with the Dotnet framework and C# and Bootstrap framework
